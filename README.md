# 🏠 FlatSplit

A modern expense sharing application for roommates built with **HTML, CSS, JavaScript, Firebase Firestore, and GitHub Pages**.

FlatSplit helps roommates track shared expenses, calculate spending, view analytics, manage monthly history, and synchronize data in real time.

---

## ✨ Features

- 🔐 Secure 3-user login using personal secret codes
- 🔄 Firebase Firestore Realtime Sync
- 💰 Shared expense management
- 📊 Analytics Dashboard
- 📅 Monthly History
- 🗑️ Trash & Restore
- 📦 Monthly Archive
- 👤 Expense Ownership Protection
- 🌙 Premium Dark Theme
- 📱 Installable PWA
- 📤 Export Reports
- 💬 WhatsApp Report Sharing
- ⚡ GitHub Pages Deployment
- 📱 Responsive Design
